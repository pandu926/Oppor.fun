# Arc Microgrants: public project candidates

Research date: 2026-10-08.

Count: **112 distinct project repositories with an event indication**. This is not an official participant count and does not establish that each project is submitted, eligible, live, or independently tested. Separate projects by the same builder are counted separately.

Method: GitHub repository search in README/name across four query/page combinations returned 119 unique repositories. 116 root README files were retrieved; 115 matched an event-related phrase or document path. Excluded the competence-graph parent repository, I-frenzy builder profile, chain-kits general toolkit, and SettlementRegistry (its README match was only its repository name). Added Arc Split from its separately reviewed GRANT-DRAFT.md.

README claims and roadmap features remain self-reported. Three inaccessible README files and one repository without an event phrase were excluded.
