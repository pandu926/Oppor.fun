# Development

Use the pinned toolchain and lockfiles. Component environment examples document the required settings; keep actual credentials and signing keys outside Git.

## Frontend

Requires Node.js 22.12 or newer.

```sh
cd frontend
npm ci
cp .env.example .env.local
npm run dev
```

Configure the API origin, chain, RPC, explorer, and verified factory together. Public frontend variables must not contain secrets. Production configuration targets Arc mainnet; browser regression fixtures explicitly configure development test data.

```sh
npm run typecheck
npm run test:unit
npx playwright install chromium
npm test
npm run build
```

See [the frontend guide](../frontend/README.md) for routes, prerendering, wallet configuration, and deployment requirements.

## Backend

Use the Rust toolchain pinned in `backend/rust-toolchain.toml`. Configure PostgreSQL, Redis, private object storage, and the matching network deployment using `backend/.env.example`.

```sh
cd backend
cargo fmt --all -- --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked --lib
cargo build --release --locked
```

The complete integration suite starts isolated PostgreSQL, Redis, S3-compatible storage, and Anvil fixtures:

```sh
bash scripts/test.sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/validate-openapi.py
```

See [backend setup](../backend/README.md) and [the operations guide](../backend/RUNBOOK.md) for migrations, service configuration, and production requirements.

## Contracts

Requires Foundry v1.5.1 and the compiler configured in `contracts/foundry.toml`.

```sh
cd contracts
bash scripts/bootstrap.sh
forge fmt --check
forge test
python3 scripts/deployment-smoke.py
python3 scripts/export-artifacts.py --check
python3 scripts/test-security-gates.py
```

Dependencies are pinned by commit. The static-analysis review is bound to source hashes; review findings before updating its baseline. See [the contracts guide](../contracts/README.md).

## Generated interfaces

The OpenAPI generator is the source for API schemas. Regenerate the frontend types when an API schema changes:

```sh
python3 backend/scripts/generate-openapi.py
cd frontend
python3 scripts/generate-types.py
npx prettier --write src/lib/types.ts
```

Contract ABI and bytecode exports are checked against the pinned build. The frontend deployment artifact is generated from those contract artifacts; follow the component guide rather than editing generated bytecode or types manually.
